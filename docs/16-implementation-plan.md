## نصايح عملية

**١. شاشة واحدة في الجلسة.** ماتديش Claude Code ٥ شاشات مرة واحدة — الجودة بتقل.

**٢. راجع كل شاشة قبل ما تعدّي.** لو سبت غلطة في مكوّن مشترك، هتتكرر في ٩٠ شاشة.

**٣. Commit بعد كل شاشة.** لو حاجة بوّظت، ترجع خطوة واحدة مش عشرة.

**٤. لما Claude Code يسأل — جاوب بدقة.** السؤال معناه إن فيه غموض حقيقي، والإجابة السريعة الغلط بتكلّف أكتر.

**٥. اختبر على موبايل الوالد بدري.** الشاشة في المتصفح غير الشاشة في إيده وهو واقف في الحوش.
